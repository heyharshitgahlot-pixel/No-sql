# Task 07: Neo4j Student-Course Relationship Graph

## Problem Statement
Create a simple Student–Course relationship graph using Neo4j.
- Create nodes for: `Students`, `Courses`
- Create relationships: `ENROLLED_IN`

Perform Cypher queries to:
1. Create at least five students and three courses.
2. Display all students.
3. Find students enrolled in a particular course.
4. Display all courses taken by a particular student.
5. Add and remove a relationship.

## How to Run
```bash
cypher-shell -u neo4j -p password -f student-course.cypher
```
