# Task 14: MapReduce on Database Dataset

## Problem Statement
Implement a simple MapReduce operation on a database dataset.
Use a student dataset containing:
`Student_ID`, `Name`, `Course`, `Marks`

Perform MapReduce operation to:
1. Calculate the number of students in each course.
2. Calculate the average marks for each course.
3. Display the result of the Map and Reduce operations.

## How to Run
```bash
node mapreduce.js
```
