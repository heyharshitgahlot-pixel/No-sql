# Task 01: Student Activity Tracking System

## Problem Statement
Design a Student Activity Tracking System in MongoDB that stores student details, enrolled courses, attendance, skills, and recent activities. Perform queries to retrieve students based on different activity conditions.

## Key Features
- Embedded activity logs with dates, scores, and event types
- Multi-key index on skills array
- Range query on attendance percentage

## Run
```bash
node solution.js
```
