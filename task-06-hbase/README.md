# Task 06: Apache HBase Column Family Operations

## Problem Statement
Using HBase, create a table named `Students` with suitable column families such as `personal` and `academic`.
1. Insert at least five student records.
2. Retrieve a particular student's details.
3. Update student information.
4. Display all records.
5. Delete a student record.

## How to Run
```bash
hbase shell students.hbase
```
