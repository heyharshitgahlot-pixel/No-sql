# Task 02: MongoDB CRUD Operations

## Problem Statement
Create a MongoDB database named `CollegeDB` and a collection named `Students`. Insert at least five student documents containing:
`Student_ID`, `Name`, `Course`, `Semester`, `Marks`

Perform the following operations:
1. Display all documents.
2. Find students from a particular course.
3. Update marks of a student.
4. Delete one student.
5. Count the total number of students.

## How to Run
```bash
node students-crud.js
```
