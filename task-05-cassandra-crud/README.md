# Task 05: Cassandra Keyspace and Students Table

## Problem Statement
Create a Cassandra keyspace named `CollegeDB` and a table named `Students` with:
`Student_ID`, `Name`, `Course`, `Semester`, `Marks`

1. Insert at least five records.
2. Display all records.
3. Retrieve students from a particular course.
4. Update the marks of a student.
5. Delete a student record.

## How to Run
```bash
cqlsh -f students.cql
```
